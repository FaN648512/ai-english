一、选词原则

①
日常优先:优先收「用 AI 聊天 / 写码 / 做图 / 建工作流」时高频出现的词,而不是论文术语。
②
由易到难:8 个主题从「入门聊天」到「行业前沿」层层递进;每个主题内部 25 词也按易到难排列。
③
专业词少量穿插:像 transformer / attention / RAG / RLHF 这类专业词只占少数,放到中后段,作为进阶内容。
④
难度 3 档:1=日常必会 / 2=进阶理解 / 3=专业概念。学习者先吃透 1,再逐步上 2、3。
🎯 = 老板点名提到的词(LLM / agent / work / code / design / AGI / token / markdown / tool / fork)
